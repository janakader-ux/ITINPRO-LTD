ITIN Pro Hostinger Upload Pack

Upload the contents of this folder into the public_html folder for itinpro.uk.

For GitHub deployment, see README.md. Keep index.html in the repository root and deploy the main branch to /public_html.

Included:
- index.html
- smart-itin-form.html
- itin-document-rules.html
- blog pages
- styles.css
- robots.txt
- sitemap.xml
- .htaccess and 404.html
- README.md with GitHub/Hostinger instructions
- assets folder with logo files

Important compliance note:
This site intentionally does not use the official IRS logo, IRS seal or IRS eagle. It uses custom text badges only.

This combined release includes the reviewed Claude SEO article library. It intentionally does not activate the supplied PHP passport-upload, admin or SumUp code because those components still require live credentials, confirmed privacy information and security testing.

The Smart ITIN Form currently uses a mailto action. For production, connect the form to Hostinger Forms, Brevo, or another secure CRM/form handler.
