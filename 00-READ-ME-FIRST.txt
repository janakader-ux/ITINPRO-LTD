DEPLOYMENT — IMPORTANT
----------------------
Extract ITIN-Pro-Website-Deployment-v8.zip into an EMPTY GitHub repository root. You should immediately see package.json, package-lock.json, app, components, lib, public and README.md. Do not upload the four package ZIP files themselves into the website repository.

The app, components, lib and public directories must remain as directories. Flattening those directories would break Next.js imports, routing, images and downloads.

Hostinger must use a plan that supports Node.js applications:

Install command: npm ci
Build command: npm run build
Start command: npm run start

Add these hosting environment variables:

NEXT_PUBLIC_SITE_URL=https://itinpro.uk
SUPABASE_URL=
SUPABASE_SERVICE_ROLE_KEY=
RESEND_API_KEY=
RESEND_FROM_EMAIL=enquiries@itinpro.uk
ENQUIRY_RECIPIENTS=Shan@itinpro.uk,Taz@itinpro.uk
NEXT_PUBLIC_GA_MEASUREMENT_ID=

The enquiry form intentionally remains unavailable until Supabase and Resend are configured. Do not add real passport numbers, tax identification numbers or bank details to the general website form.
